# AI Security Magazine Project

🔒 **A mesterséges intelligencia biztonságának szakmai magazinja**

## 📖 Áttekintés

Ez a projekt egy professzionális, havi rendszerességgel megjelenő AI Security magazin, amely széles közönséget szólít meg - a kíváncsi laikusoktól az üzleti vezetőkön át a biztonsági szakemberekig.

## 🎯 Célok

- **Széles elérés:** Mindenki számára érthető és érdekes tartalom
- **Professzionális:** Magas színvonalú tartalom és design
- **Gyakorlati:** Használható tudás és útmutatók
- **Közösségépítés:** AI Security szakemberek összekapcsolása

## 📂 Struktúra

```
magazine/          # Magazin forrás fájlok és generált PDF
  ├── content/     # HTML és LaTeX források
  ├── output/      # Generált PDF-ek
  └── README.md    # Részletes dokumentáció
```

## 🚀 Gyors kezdés

```bash
cd magazine/
python3 generate_pdf.py
```

További részletekért lásd: [magazine/README.md](magazine/README.md)
