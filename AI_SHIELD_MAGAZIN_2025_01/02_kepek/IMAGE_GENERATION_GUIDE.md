**DALL-E 3 Ajánlott Beállítások:**
- **Quality:** HD / Standard
- **Style:** Natural (realistic nem vivid)
- **Size:** 1024x1024 vagy 1024x1792 (majd crop/resize)

**Post-processing:**
1. Optimalizáció: TinyPNG vagy ImageOptim
2. Format: PNG (transparency) vagy JPG (no transparency, smaller)
3. Compression: 80-90% quality

import json

# Promptok betöltése
with open('image_prompts.json') as f:
    prompts = json.load(f)

# Generálás
for img_name, prompt in prompts.items():
    response = openai.Image.create(
        prompt=prompt,
        n=1,
        size="1024x1024"
